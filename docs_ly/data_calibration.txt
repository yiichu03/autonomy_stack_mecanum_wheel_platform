## The coordinate frames

with respect to the wheeled robot,
lidar: x left, y behind, z up
RGB: x right, y down, z forward 
depth: x right, y down, z forward 
thermal left: x right, y down, z forward
thermal right: x right, y down, z forward
wheeled robot base link frame: x forward, y left, z up

### lidar RGB camera calibration

We estimate the rigid transform from the RGB camera frame to the LiDAR frame using the open-source tool [direct_visual_lidar_calibration](https://github.com/koide3/direct_visual_lidar_calibration)

```
"lidar_T_camera": [
      -0.02671709287258754,
      -0.07986985425426218,
      -0.07194136971184459,
      -0.0025930314846405633,
      0.7233645800633655,
      -0.6904201829671065,
      -0.007545293177736468
    ]
```
lidar_T_camera: [x, y, z, qx, qy, qz, qw] (i.e., p_lidar = lidar_T_camera * p_camera)
